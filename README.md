# web

LibreCourseUY web

Member products appear in the homepage's **Built by our members** section and at `/showcase/`.
See [the submission guide](CONTRIBUTING.md#member-products) to propose a product through a PR.

## Development

Run `pnpm dev`, then open `http://localhost:4321/`. To load the public project catalog
during local development, run:

```sh
PUBLIC_AWESOME_FEED_URL=https://raw.githubusercontent.com/LibreCourseUY/awesome-librecourseuy/master/public/entries.json pnpm dev
```
